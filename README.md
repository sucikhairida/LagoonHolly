# LagoonHolly

Syncs database schema changes across multiple PostgreSQL instances in a production environment.

LagoonHolly is built to be simple and practical, focusing on doing one thing well.

**Why LagoonHolly?**

- Syncs database schema changes across
- multiple PostgreSQL instances in a
- production environment

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/LagoonHolly.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
